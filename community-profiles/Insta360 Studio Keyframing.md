# Insta360 Studio Keyframing

Reframe 360 footage in Insta360 Studio from a controller: steer the view with the sticks,
drop keyframes, and play/pause without the click-drag, zoom, K, space-bar loop.
Built for a PS5 DualSense; any controller with two sticks works. No macros, scripts or
external automations are required.

Profile contributed by **Jared Alexander** ([@jared_alexandah](https://www.instagram.com/jared_alexandah/)),
a tap dancer in NYC who edits his Insta360 X4 busking footage with it.

## Setup and first action

1. Import **Insta360 Studio Keyframing** from the community library.
2. Open a 360 clip in Insta360 Studio and click once in the preview so it has focus.
3. Move the left stick to steer the view, then press **Square / X** to set a keyframe.
4. Tune the left-stick mouse sensitivity until camera moves feel right to you.

## Controls

| PlayStation / Xbox | Action |
| --- | --- |
| Left stick | Move the pointer (drag the view while L1 / LB is held) |
| Right stick | Scroll (zoom the view) |
| Cross / A, R2 / RT | Play / pause (Space) |
| Square / X | Set keyframe (K) |
| Triangle / Y | Undo (⌘Z) |
| R1 / RB | Redo (⇧⌘Z) |
| Circle / B | ⇧⌘; |
| L1 / LB, R3 | Hold the left mouse button |
| L2 / LT | Scroll down |
| Touchpad click / tap | Left click |

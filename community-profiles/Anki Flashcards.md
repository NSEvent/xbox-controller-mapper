# Anki Flashcards — First Study Session

Use this profile for ordinary Anki flashcards. No add-on or card-template changes
needed. The separate **Anki - AnKing (USMLE)** profile has different bindings and
optional AnKing-specific features.

## 1. Import and open Anki

1. Select **Anki Flashcards** in Community Profiles, then click **Import**.
2. Allow ControllerKeys in **System Settings → Privacy & Security → Accessibility**.
3. Connect your controller. Its buttons should light up in ControllerKeys.
4. Open the **Anki desktop app**, choose a deck, and click **Study Now**.

The profile selects automatically when Anki is the frontmost app. It supports
the current Anki app and the older Anki launcher. AnkiWeb in a browser is a
different app and does not activate this desktop profile automatically.

## 2. Try one card

The labels below use Xbox-style button names; use the matching positions on
PlayStation or other controllers, as shown in ControllerKeys.

| Button | While studying |
|---|---|
| A (bottom face button) | Show answer; press again to grade Good |
| B (right face button) | Again (1) |
| X (left face button) | Hard (2) |
| Y (top face button) | Easy (4) |
| Right Bumper | Good (3) |
| Left Trigger | Undo the last review (Command+Z) |

Try a disposable practice card first. **A second press of A grades the card**;
it is not only a preview. Keep Anki's review window focused, not an edit field.
The full bindings below also include editing and card-management shortcuts.

## 3. Check reconnect and relaunch

Disconnect and reconnect the controller, return to Anki's review screen, then
try A on a practice card. Quit and reopen ControllerKeys: the imported profile
should still be in the sidebar and select when you switch back to Anki.

## If nothing happens

- **No button lights:** check pairing/cable and the input mode for your controller.
  Some generic/HID controllers need Input Monitoring too.
- **Buttons light, but Anki does nothing:** finish the safe controller-test step,
  enable mapping, check Accessibility, and focus the review screen.
- **Wrong profile selected:** in the Anki profile's linked-app settings, select
  the installed Anki app. An older imported profile may only link the old launcher.
- **Download failed:** the picker keeps your selection and shows the error.
  Retry Import after reconnecting; successful imports are not repeated.

Anki's official shortcut reference: https://docs.ankiweb.net/studying.html
